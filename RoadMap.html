How to use the roadmap

Do not skip gates
1. One main stack

Python → NumPy/Pandas → SQL → scikit-learn → PyTorch → Hugging Face → FastAPI → Docker.

2. 70 / 20 / 10

70% coding + projects, 20% concepts, 10% reading/revision. Avoid tutorial-only learning.

3. Weekly proof

Every week ends with something runnable: notebook, script, experiment, API, model or documented project.

4. Build depth first

Do not jump to agents before you can explain data, ML training, neural networks and APIs.

Weekly operating system

Repeat every month
Mon–Thu · Learn + code

60–90 min concepts, then 60–90 min implementation. Re-code examples without copy/paste.

Friday · Review

Revisit weak concepts, write short notes, debug old code and solve 1–2 interview problems.

Saturday · Project

4–6 focused hours on the current project: feature, experiment, tests, README or deployment.

Sunday · Reset

Review the week, push code, update progress, plan the next 7 days and revisit one older topic.

Always-on skills

Small daily habit, not a separate subject
DSA

Start with 30–45 minutes/day. Focus on arrays, strings, hash maps, two pointers, sliding window, stacks, queues, trees and basic DP.

SQL

Keep practicing even after Month 2. Querying data is a core AI/data engineering skill.

Git + Linux

Use branches, meaningful commits, virtual environments, shell commands and clean project structure continuously.

Communication

Every project should be explainable in 60 seconds: problem → approach → trade-offs → result.

Target outcome: a strong AI/ML portfolio with deployed projects, solid fundamentals, and interview readiness.
